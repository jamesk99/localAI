# ============================================================================
# OLLAMA MODELS SETUP (PowerShell Commands)
# ============================================================================
# This RAG AI platform requires Ollama to be installed and running with specific models.
# Follow these steps to set up all required models:

# 1. INSTALL OLLAMA (if not already installed)
# Download from: https://ollama.ai
# Or via PowerShell:
#   winget install Ollama.Ollama

# 2. START OLLAMA SERVICE
# PowerShell command:
#   ollama serve
# Note: Keep this running in a separate terminal window

# 3. PULL REQUIRED MODELS
# The following models are used by this RAG system (configured in src/config.py):

# --- EMBEDDING MODEL (required for document ingestion and query retrieval) ---
# Model: bge-m3 (BAAI/bge-m3)
# Purpose: Converts text to vector embeddings for semantic search
# Size: ~2.2 GB
# PowerShell command:
#   ollama pull bge-m3

# --- PRIMARY LLM (for answer generation) ---
# Model: qwen3:30b (default in config.py)
# Purpose: Main language model for generating answers from retrieved context
# Size: ~17 GB (requires significant RAM - 128GB recommended)
# Context window: 131K tokens (256K max)
# PowerShell command:
#   ollama pull qwen3:30b

# --- FALLBACK LLM (optional but recommended) ---
# Model: llama3:latest (default fallback in config.py)
# Purpose: Backup model if primary LLM fails or runs out of memory
# Size: ~4.7 GB (8B parameter version)
# PowerShell command:
#   ollama pull llama3:latest

# 4. VERIFY MODELS ARE INSTALLED
# PowerShell command:
#   ollama list
# Expected output should show: bge-m3, qwen3:30b, llama3:latest

# --- RERANKER MODEL (automatically downloaded by sentence-transformers) ---
# Model: BAAI/bge-reranker-v2-m3 (configured in src/query.py)
# Purpose: Cross-encoder for reranking retrieved chunks by relevance
# Size: ~560 MB
# NOTE: This model is NOT pulled via Ollama!
# It's automatically downloaded from HuggingFace when you first run the system
# with USE_RERANKING=true in your .env file.
# The model will be cached in: C:\Users\<username>\.cache\huggingface\hub\
# 
# To pre-download (optional):
# PowerShell command:
#   python -c "from sentence_transformers import CrossEncoder; CrossEncoder('BAAI/bge-reranker-v2-m3')"
#
# Alternative reranker models (modify src/query.py line 174):
#   BAAI/bge-reranker-base        # ~280MB, faster, good quality
#   BAAI/bge-reranker-large       # ~1.1GB, best quality, slower

# 5. ALTERNATIVE MODELS (if you have less RAM or different requirements)
# You can modify src/config.py or .env file to use different models:

# Lighter LLM options (if you have less than 128GB RAM):
#   ollama pull llama3.2:3b      # ~2GB, good for testing
#   ollama pull qwen2.5:7b       # ~4.7GB, balanced performance
#   ollama pull mistral:7b       # ~4.1GB, fast and efficient

# Alternative embedding models:
#   ollama pull nomic-embed-text # ~274MB, English-focused
#   ollama pull mxbai-embed-large # ~669MB, high quality

# ============================================================================
# RUNNING THE RAG SYSTEM
# ============================================================================
# After installing packages and pulling Ollama models:

# 1. Ensure Ollama is running:
#   ollama serve

# 2. Ingest documents (first time setup):
#   python src/ingest.py
# This will process all documents in data/raw/ and create the vector database

# 3. Start the web application:
#   python src/app.py
# Default URL: http://localhost:8000
# Default credentials: raguser / changeme (configure in .env)

# 4. Or run interactive query mode:
#   python src/query.py

# 5. Run benchmarks (optional):
#   python src/benchmark.py
#   python src/benchmarkv2.py --tier1
